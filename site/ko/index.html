자주 묻는 질문

Huescribe는 무엇을 하나요?

Chrome 확장 프로그램이에요. 어떤 웹사이트든 원하는 부분을 클릭하면, AI 앱이 그 디자인을 내 사이트에 만들 수 있는 프롬프트를 써 줘요.

무료인가요?

네. 구매할 요금제도, 사용 한도도 없고, API 키도 필요 없어요.

AI 앱에 그냥 스크린샷을 주면 안 되나요?

스크린샷은 모양은 보여 주지만 수치는 없어서, AI가 색상·글자 크기·간격·호버 시간을 짐작하게 돼요. Huescribe는 페이지에서 정확한 값을 읽고, 이미지도 함께 넣을 수 있어요.

코딩을 알아야 하나요?

아니요. 만드는 일은 AI 앱이 해요.

어떤 AI 앱과 함께 쓸 수 있나요?

Claude Code, Cursor, ChatGPT, Gemini, Claude, Windsurf, Copilot, Lovable, v0, Bolt와 함께 쓸 수 있어요. 프롬프트는 일반 텍스트라서 Codex, Replit 등 다른 앱에서도 돼요.

React, Tailwind나 제가 쓰는 프레임워크에서도 되나요?

네. 프롬프트는 코드가 아니라 디자인을 설명하고, 프로젝트에서 이미 쓰는 기술로 만들라고 AI 앱에 알려 줘요.

다른 사이트의 디자인을 가져와도 괜찮나요?

Huescribe는 페이지가 아니라 아이디어를 가져와요. 색상·크기·간격·모션을 설명할 뿐, 글·이미지·로고·코드는 복사하지 않고, 내 글과 브랜드는 그대로 두라고 AI 앱에 알려 줘요. 사이트를 통째로 베끼지 말고 영감을 얻는 데 쓰세요.

호버 효과와 애니메이션도 복사되나요?

네. 모션을 켜면 시간, 이징, 각 동작이 일어나는 조건이 프롬프트에 들어가요.

모든 웹사이트에서 되나요?

Chrome에서 여는 모든 페이지에서 돼요. 로그인한 페이지도 포함이에요. Chrome 자체 페이지와 Chrome 웹 스토어에서는 확장 프로그램이 실행되지 않아요.

계정이나 API 키가 필요한가요?

API 키는 필요 없어요. Google로 한 번만 로그인하면 이름과 이메일은 브라우저에만 남아요. 서버로는 아무것도 보내지 않고, 프롬프트는 클립보드로 가요.

프롬프트를 DESIGN.md나 Cursor 규칙으로 저장할 수 있나요?

네. 일반 텍스트라서 AI 앱이 지침을 읽는 곳이면 어디든 저장하면 돼요.

결과가 마음에 안 들면요?

AI 앱에 바꿀 부분을 말하거나, 고른 내용을 조정해서 새 프롬프트를 복사하세요.

상표

Claude, Claude Code, Cursor, ChatGPT, Gemini, Windsurf, Copilot, Lovable, v0, Bolt, Google Chrome 및 기타 이름은 각 소유자의 상표예요. Huescribe는 이들 중 누구와도 제휴하거나 보증받지 않았어요.

빌려 온 것의 사용

Huescribe는 디자인을 설명할 뿐, 사이트의 글, 사진, 로고, 코드는 절대 복사하지 않아요. 내 사이트에 무엇을 올릴지는 사용자의 책임이에요.

개인정보

모든 작업은 브라우저 안에서 이루어져요. Google로 한 번만 로그인하면 이름과 이메일은 기기에 남고, 서버로는 아무것도 보내지 않아요. 이 웹사이트는 쿠키를 사용하지 않아요. 자세한 내용: 개인정보처리방침.

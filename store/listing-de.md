# Huescribe: Chrome Web Store listing (Deutsch, `de`)

Paste into the Store listing tab with the language set to Deutsch. Name and summary come from the package (`huescribe/_locales/de/messages.json`); they are shown here for reference.

## Name

48 of 75 characters:

Huescribe: Website-Design als KI-Prompt kopieren

## Summary

130 of 132 characters:

Kopiere Farben, Schriften, Layout und Animationen jeder Website als fertigen Prompt für Claude Code, Cursor, Lovable, v0 und Bolt.

## Description

```
Du hast ein Website-Design gesehen, das dir gefällt? Bring es mit KI auf deine eigene Seite, ohne die Seite zu kopieren.

Huescribe ist ein kostenloses Seitenpanel für Chrome, das jeden Teil einer Website in einen KI-Prompt zum direkten Einfügen verwandelt. Klick auf eine Preistabelle, einen Hero-Bereich, eine Navigationsleiste oder einen Button mit schönem Hover-Effekt, wähle, was du davon willst (Farben, Schriften, Layout oder Animation), und Huescribe schreibt einen präzisen Design-Prompt für die KI-App, mit der du baust: Claude Code, Cursor, ChatGPT, Lovable, v0, Bolt, Windsurf, GitHub Copilot, Gemini oder Replit.

SO FUNKTIONIERT ES
1. Klick auf irgendetwas auf einer Webseite. Mit den Pfeiltasten erweiterst du die Auswahl auf einen ganzen Abschnitt; oder zieh einen Rahmen um einen beliebigen Bereich.
2. Wähle, was du übernimmst: Farben, Schriften, Layout, Animation. Nimm nur, was du brauchst; deine Seite behält den Rest ihres eigenen Stils.
3. Kopiere den Prompt und füge ihn in deine KI-App ein. Sammle vorher mehrere Teile, dann gehen sie als ein einziger Prompt raus.

WAS ES VON EINER WEBSITE LIEST
• Farbpalette, Verläufe und Kontrast, mit den genauen Hex-Werten
• Typografie: Schriftfamilien, Größen, Schriftstärken, Zeilenhöhe und Laufweite, übertragen auf die Schriften, die du schon nutzt
• Layout und Abstände: Grid- und Flex-Spalten, Gaps, Padding, Breiten und wie es sich auf dem Smartphone ändert
• Hover-Effekte, Button-Klicks und CSS-Animationen, mit Timing und Easing
• Scroll-Effekte und Bewegungen, die du aufzeichnest, während du die Seite benutzt
• Schatten, Rahmen und Eckenradien: die kleinen Details, die eine UI fertig wirken lassen

WARUM LEUTE ES NUTZEN
• Vibe Coding mit echten Vorlagen statt „mach es wie diese Seite“
• Frontend-Entwickler und Indie Hacker, die eine Komponente passend zu einem gesehenen Design wollen
• Designer, die der KI exakte Styles statt Screenshots geben wollen
• Alle, die eine Landingpage, Preisseite, ein Dashboard oder Portfolio mit KI neu bauen

IDEEN ÜBERNEHMEN, KEINE SEITEN
Huescribe beschreibt Design. Es kopiert nie Texte, Fotos, Logos oder Code einer Website, und der Prompt sagt deiner KI-App, deine eigenen Texte, Bilder und deine Marke zu behalten.

KOSTENLOS UND PRIVAT
Melde dich einmal mit Google an; dein Name und deine E-Mail bleiben in diesem Browser. Kein API-Schlüssel, keine Analytics und kein Huescribe-Server. Alles läuft in deinem Browser; der Prompt landet nur in deiner Zwischenablage. Huescribe liest eine Seite nur, wenn du dort etwas auswählst, und schaltet sich ab, wenn du das Panel schließt.

Verfügbar in 15 Sprachen, darunter English, Español, Português, Français, Deutsch, Русский, 日本語, 한국어 und 中文. Öffne es über das Symbol in der Symbolleiste oder mit Alt+Shift+P.
```

# Huescribe: Chrome Web Store listing (Português (Brasil), `pt_BR`)

Paste into the Store listing tab with the language set to Português (Brasil). Name and summary come from the package (`huescribe/_locales/pt_BR/messages.json`); they are shown here for reference.

## Name

60 of 75 characters:

Huescribe: copie o design de qualquer site como prompt de IA

## Summary

131 of 132 characters:

Copie cores, fontes, layout e animações de qualquer site em um prompt pronto para colar no Claude Code, Cursor, Lovable, v0 e Bolt.

## Description

```
Viu um design de site que você adorou? Leve para o seu próprio site com IA, sem copiar o site.

O Huescribe é um painel lateral gratuito do Chrome que transforma qualquer parte de um site em um prompt de IA pronto para colar. Clique em uma tabela de preços, uma seção hero, uma barra de navegação ou um botão com um efeito hover bacana, escolha o que você quer dele (cores, fontes, layout ou movimento) e o Huescribe escreve um prompt de design preciso para o app de IA que você usa para programar: Claude Code, Cursor, ChatGPT, Lovable, v0, Bolt, Windsurf, GitHub Copilot, Gemini ou Replit.

COMO FUNCIONA
1. Clique em qualquer coisa na página. As setas do teclado ampliam a seleção para uma seção inteira; você também pode arrastar uma caixa em volta de qualquer área.
2. Escolha o que levar: cores, fontes, layout, movimento. Leve só o que precisa; seu site mantém o resto do próprio estilo.
3. Copie o prompt e cole no seu app de IA. Junte várias partes antes e elas vão juntas em um único prompt.

O QUE ELE LÊ DE UM SITE
• Paleta de cores, gradientes e contraste, com os valores hex exatos
• Tipografia: famílias de fontes, tamanhos, pesos, altura de linha e espaçamento entre letras, ajustados às fontes que você já usa
• Layout e espaçamento: colunas grid e flex, gaps, padding, larguras e como tudo muda no celular
• Efeitos hover, cliques em botões e animações CSS, com duração e easing
• Efeitos de rolagem e movimentos que você grava usando a página
• Sombras, bordas e cantos arredondados: os pequenos detalhes que deixam uma interface com cara de pronta

POR QUE AS PESSOAS USAM
• Vibe coding com referências reais em vez de "deixa parecido com aquele site"
• Desenvolvedores front-end e indie hackers que querem um componente igual a um design que viram
• Designers que querem passar para a IA estilos exatos em vez de prints
• Quem está refazendo com IA uma landing page, página de preços, dashboard ou portfólio

PEGUE IDEIAS, NÃO PÁGINAS
O Huescribe descreve o design. Ele nunca copia textos, fotos, logos ou código de um site, e o prompt pede ao seu app de IA que mantenha seus próprios textos, imagens e marca.

GRÁTIS E PRIVADO
Entre uma vez com o Google; seu nome e e-mail ficam neste navegador. Sem chave de API, sem analytics e sem servidor do Huescribe. Tudo roda no seu navegador; o prompt vai só para a sua área de transferência. O Huescribe lê uma página apenas quando você escolhe algo nela e se desliga quando você fecha o painel.

Disponível em 15 idiomas, incluindo English, Español, Português, Français, Deutsch, Русский, 日本語, 한국어 e 中文. Abra pelo ícone na barra de ferramentas ou com Alt+Shift+P.
```

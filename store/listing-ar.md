## Description

```
هل أعجبك تصميم موقع ما؟ انقله إلى موقعك بالذكاء الاصطناعي، من دون نسخ الموقع نفسه.

Huescribe لوحة جانبية مجانية في Chrome تحوّل أي جزء من موقع إلى طلب (Prompt) للذكاء الاصطناعي جاهز للصق. انقر على جدول أسعار أو قسم رئيسي (Hero) أو شريط تنقّل أو زر بتأثير Hover جميل، واختر ما تريده منه (الألوان أو الخطوط أو التخطيط أو الحركة)، فيكتب Huescribe طلب تصميم دقيقًا لتطبيق الذكاء الاصطناعي الذي تبرمج به: Claude Code أو Cursor أو ChatGPT أو Lovable أو v0 أو Bolt أو Windsurf أو GitHub Copilot أو Gemini أو Replit.

كيف يعمل
1. انقر على أي عنصر في الصفحة. توسّع مفاتيح الأسهم التحديد ليشمل قسمًا كاملًا، ويمكنك أيضًا رسم مربع حول أي منطقة.
2. اختر ما تأخذه: الألوان، الخطوط، التخطيط، الحركة. خذ ما تحتاجه فقط، ويحتفظ موقعك ببقية أسلوبه الخاص.
3. انسخ الطلب والصقه في تطبيق الذكاء الاصطناعي. اجمع عدة أجزاء أولًا لتُرسل معًا في طلب واحد.

ما الذي يقرؤه من الموقع
• لوحة الألوان والتدرجات والتباين، مع قيم Hex الدقيقة
• الطباعة (Typography): عائلات الخطوط وأحجامها وأوزانها وارتفاع السطر والتباعد بين الحروف، مع مطابقتها للخطوط التي تستخدمها أصلًا
• التخطيط والمسافات: أعمدة Grid وFlex والفجوات والحشو (Padding) والعروض، وكيف يتغير كل ذلك على الجوال
• تأثيرات Hover والضغط على الأزرار وحركات CSS، مع توقيتها ومنحنى التسارع (Easing)
• تأثيرات التمرير والحركة التي تسجّلها أثناء استخدام الصفحة
• الظلال والحدود وتدوير الزوايا: التفاصيل الصغيرة التي تجعل الواجهة تبدو مكتملة

لماذا يستخدمه الناس
• البرمجة بالذكاء الاصطناعي (Vibe Coding) بمراجع حقيقية بدلًا من «اجعله مثل ذلك الموقع»
• مطورو الواجهات الأمامية (Front-end) والمطورون المستقلون الذين يريدون مكوّنًا يطابق تصميمًا رأوه
• المصممون الذين يريدون إعطاء الذكاء الاصطناعي أنماطًا دقيقة بدلًا من لقطات الشاشة
• كل من يعيد بناء صفحة هبوط (Landing Page) أو صفحة أسعار أو لوحة تحكم أو معرض أعمال بالذكاء الاصطناعي

خذ الأفكار لا الصفحات
يصف Huescribe التصميم. لا ينسخ أبدًا نصوص الموقع أو صوره أو شعاراته أو شيفرته، ويوجّه الطلب الناتج تطبيق الذكاء الاصطناعي إلى الحفاظ على نصوصك وصورك وهويتك الخاصة.

مجاني وخاص
سجّل الدخول مرة واحدة عبر Google؛ يبقى اسمك وبريدك في هذا المتصفح. لا مفتاح API، ولا تحليلات، ولا خادم لـ Huescribe. كل شيء يعمل داخل متصفحك، والطلب يذهب إلى الحافظة فقط. لا يقرأ Huescribe الصفحة إلا عندما تختار شيئًا فيها، ويتوقف عند إغلاق اللوحة.
```

## Description

```
看到喜欢的网站设计？用 AI 把它搬到你自己的网站上，而无需照搬整个网站。

Huescribe 是一款免费的 Chrome 侧边栏扩展，能把网站的任意部分变成可直接粘贴的 AI 提示词。点击价格表、首屏 Hero 区块、导航栏，或带有出色悬停效果的按钮，选择你想要的部分（颜色、字体、布局或动效），Huescribe 就会为你使用的 AI 编程工具写出精准的设计提示词：Claude Code、Cursor、ChatGPT、Lovable、v0、Bolt、Windsurf、GitHub Copilot、Gemini 或 Replit。

使用方法
1. 点击网页上的任意元素。用方向键可把选区扩大到整个区块；也可以拖出一个框，框选任意区域。
2. 选择要提取的内容：颜色、字体、布局、动效。只取你需要的，你的网站其余部分仍保持自己的风格。
3. 复制提示词，粘贴到你的 AI 工具中。先收集多个部分，它们会合并成一条提示词。

它能从网站读取什么
• 配色方案、渐变和对比度，附带精确的 HEX 色值
• 字体排版：字体族、字号、字重、行高和字间距，并映射到你已在使用的字体
• 布局与间距：Grid 和 Flex 列、间隙、内边距、宽度，以及在移动端的变化
• 悬停（hover）效果、按钮按下效果和 CSS 动画，含时长与缓动曲线
• 你在使用页面时录制的滚动效果和动效
• 阴影、边框和圆角：让 UI 显得精致完整的设计细节

为什么大家都在用
• 用真实参考进行 vibe coding（氛围编程），而不是“做得像那个网站一样”
• 想做出与所见设计一致的组件的前端开发者和独立开发者
• 想给 AI 精确样式而不是截图的设计师
• 任何用 AI 重做落地页、定价页、仪表盘或作品集的人

借鉴灵感，而非照搬页面
Huescribe 只描述设计。它从不复制网站的文字、图片、Logo 或代码，提示词还会要求你的 AI 工具保留你自己的文案、图片和品牌。

免费且注重隐私
只需用 Google 登录一次；你的姓名和邮箱只保存在这个浏览器里。无需 API 密钥、没有数据分析，也没有 Huescribe 服务器。一切都在你的浏览器中运行；提示词只会进入你的剪贴板。只有当你在页面上选择内容时，Huescribe 才会读取该页面；关闭面板后即停止工作。

支持 15 种语言，包括 English、Español、Português、Français、Deutsch、Русский、日本語、한국어 和 中文。点击工具栏图标或按 Alt+Shift+P 即可打开。
```

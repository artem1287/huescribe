## Description

```
마음에 드는 웹사이트 디자인을 발견했나요? 사이트를 베끼지 않고도 AI로 내 사이트에 가져올 수 있어요.

Huescribe는 웹사이트의 어떤 부분이든 바로 붙여 넣을 수 있는 AI 프롬프트로 바꿔 주는 무료 Chrome 사이드 패널이에요. 가격표, 히어로 섹션, 내비게이션 바, 멋진 호버 효과가 있는 버튼 등을 클릭하고 가져올 요소(색상, 글꼴, 레이아웃, 모션)를 고르면, Huescribe가 사용 중인 AI 코딩 앱에 맞는 정확한 디자인 프롬프트를 작성해 드려요. 지원 앱: Claude Code, Cursor, ChatGPT, Lovable, v0, Bolt, Windsurf, GitHub Copilot, Gemini, Replit.

사용 방법
1. 페이지에서 아무 요소나 클릭하세요. 방향키로 선택 범위를 섹션 전체로 넓힐 수 있고, 드래그해서 원하는 영역을 박스로 지정할 수도 있어요.
2. 가져올 요소를 고르세요: 색상, 글꼴, 레이아웃, 모션. 필요한 것만 가져오면 내 사이트의 나머지 스타일은 그대로 유지돼요.
3. 프롬프트를 복사해 AI 앱에 붙여 넣으세요. 여러 부분을 먼저 모아 두면 하나의 프롬프트로 함께 전달돼요.

웹사이트에서 읽어 오는 것
• 컬러 팔레트, 그라데이션, 명암 대비와 정확한 HEX 값
• 타이포그래피: 폰트 패밀리, 크기, 굵기, 행간, 자간을 이미 쓰고 있는 글꼴에 맞춰 변환
• 레이아웃과 여백: grid·flex 컬럼, 간격, padding, 너비, 모바일에서 바뀌는 방식
• 호버 효과, 버튼 클릭 효과, CSS 애니메이션과 그 타이밍·이징
• 페이지를 사용하면서 녹화하는 스크롤 효과와 모션
• 그림자, 테두리, 모서리 둥글기: UI를 완성도 있게 보이게 하는 작은 디자인 디테일

이런 분들이 사용해요
• "저 사이트처럼 만들어 줘" 대신 실제 레퍼런스로 바이브 코딩하고 싶은 분
• 본 디자인과 똑같은 컴포넌트가 필요한 프론트엔드 개발자와 인디 해커
• 스크린샷 대신 정확한 스타일을 AI에 전달하고 싶은 디자이너
• 랜딩 페이지, 가격 페이지, 대시보드, 포트폴리오를 AI로 다시 만드는 모든 분

페이지가 아니라 아이디어를 빌려요
Huescribe는 디자인을 설명할 뿐이에요. 사이트의 텍스트, 사진, 로고, 코드는 절대 복사하지 않으며, 프롬프트에서도 AI 앱에 내 문구, 이미지, 브랜드를 그대로 유지하라고 요청해요.

무료, 그리고 프라이버시 보호
Google로 한 번만 로그인하면 돼요. 이름과 이메일은 이 브라우저에만 남아요. API 키, 분석 도구, Huescribe 서버는 없어요. 모든 작업은 브라우저 안에서 이루어지고, 프롬프트는 클립보드로만 전달돼요. Huescribe는 사용자가 페이지에서 무언가를 선택할 때만 그 페이지를 읽고, 패널을 닫으면 꺼져요.

English, Español, Português, Français, Deutsch, Русский, 日本語, 한국어, 中文을 포함해 15개 언어를 지원해요. 툴바 아이콘이나 Alt+Shift+P로 열 수 있어요.
```

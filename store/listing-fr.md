# Huescribe: Chrome Web Store listing (Français, `fr`)

Paste into the Store listing tab with the language set to Français. Name and summary come from the package (`huescribe/_locales/fr/messages.json`); they are shown here for reference.

## Name

64 of 75 characters:

Huescribe : copiez le design de n’importe quel site en prompt IA

## Summary

132 of 132 characters:

Copiez couleurs, polices, mise en page et animations d’un site : prompt prêt à coller dans Claude Code, Cursor, Lovable, v0 et Bolt.

## Description

```
Un design de site vous plaît ? Reproduisez-le sur votre propre site avec l’IA, sans copier le site.

Huescribe est un panneau latéral Chrome gratuit qui transforme n’importe quelle partie d’un site en prompt IA prêt à coller. Cliquez sur un tableau de prix, une section hero, une barre de navigation ou un bouton avec un bel effet de survol, choisissez ce que vous voulez en garder (couleurs, polices, mise en page ou animations), et Huescribe rédige un prompt de design précis pour l’outil d’IA avec lequel vous codez : Claude Code, Cursor, ChatGPT, Lovable, v0, Bolt, Windsurf, GitHub Copilot, Gemini ou Replit.

COMMENT ÇA MARCHE
1. Cliquez sur n’importe quel élément d’une page. Les flèches du clavier étendent la sélection à toute une section ; vous pouvez aussi tracer un cadre autour de n’importe quelle zone.
2. Choisissez ce que vous prenez : couleurs, polices, mise en page, animations. Ne prenez que ce dont vous avez besoin ; votre site garde le reste de son propre style.
3. Copiez le prompt et collez-le dans votre outil d’IA. Rassemblez d’abord plusieurs éléments : ils partent ensemble en un seul prompt.

CE QU’IL LIT SUR UN SITE
• Palette de couleurs, dégradés et contraste, avec les codes hex exacts
• Typographie : familles de polices, tailles, graisses, interlignage et espacement des lettres, adaptés aux polices que vous utilisez déjà
• Mise en page et espacements : colonnes grid et flex, gouttières, padding, largeurs et comportement sur mobile
• Effets hover, clics sur les boutons et animations CSS, avec leur durée et leur easing
• Effets au scroll et mouvements que vous enregistrez en utilisant la page
• Ombres, bordures et coins arrondis : les petits détails qui donnent à une interface un rendu fini

POURQUOI ON L’UTILISE
• Faire du vibe coding avec de vraies références plutôt que « fais comme ce site »
• Développeurs front-end et indie hackers qui veulent un composant fidèle à un design repéré
• Designers qui veulent donner à l’IA des styles exacts plutôt que des captures d’écran
• Toute personne qui refait une landing page, une page de tarifs, un dashboard ou un portfolio avec l’IA

S’INSPIRER, PAS RECOPIER
Huescribe décrit le design. Il ne copie jamais les textes, photos, logos ou le code d’un site, et le prompt demande à votre outil d’IA de garder vos propres textes, images et identité de marque.

GRATUIT ET PRIVÉ
Connectez-vous une fois avec Google ; votre nom et votre e-mail restent dans ce navigateur. Pas de clé API, pas de statistiques et pas de serveur Huescribe. Tout se passe dans votre navigateur ; le prompt va uniquement dans votre presse-papiers. Huescribe ne lit une page que lorsque vous y sélectionnez quelque chose et se désactive dès que vous fermez le panneau.

Disponible en 15 langues, dont English, Español, Português, Français, Deutsch, Русский, 日本語, 한국어 et 中文. Ouvrez-le avec l’icône de la barre d’outils ou Alt+Shift+P.
```

# Typography guide
Apply this style when designing or restyling my site: define it once as global tokens (CSS variables / theme config) and reusable component styles, then use it consistently. Keep my content and functionality as they are. Use free fonts only: if a font here is licensed, use the closest free match.

## Typography
Fonts:
- Fraunces (Google Fonts): h1, h2
- Satoshi (self-hosted, check license): h3, body, button, nav link, input
Scale (size / weight / line-height / letter-spacing):
- h1: 64px / 700 / 1.1 / -0.02em
- h2: 40px / 700 / 1.1 / -0.02em
- h3: 19.9px / 700 / 1.6
- body, input: 17px / 400 / 1.6
- button: 15px / 600 / 1.6
- nav link: 15px / 400 / 1.6
Feel: serif headings paired with a sans body, tight heading tracking, dramatic size contrast.
